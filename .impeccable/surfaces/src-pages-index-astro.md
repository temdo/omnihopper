# Landing page (src/pages/index.astro)

Mode: Persuade. Single page, English. Audience: defense and security procurement decision-makers qualifying a USV supplier. Action: request technical documentation (inquiry form with type select; delivered by email). Proof: deck specs, mission sectors, lifecycle services, standards. Constraints: no photography, no manufacturer names, schematic visuals only; payload drawings are illustrative and labeled schematic. Open: form delivery backend (Cloudflare function + mail service).

## Direction contract

THESIS: The page is OmniHopper's entry in a naval reference annual, its vessel drawn as a naval architect's lines plan. It refuses the dark-navy defense hero with HUD lines and a render.
OWN-WORLD: Cool white page and black ink; deep grey-green bookcloth owns whole fields (masthead band, mission section, footer); one signal orange reserved for change and the primary action. No greys, no gradients, no photos. Hairline ink rules, tabular figures, stations and dimension callouts as the component language. Lines-plan drawing in three views (profile, half-breadth, body plan).
STORY: The visitor sees exactly what the vessel is and measures, picks their mission and watches the drawing and figures answer, learns one supplier covers adaptation, trials and sustainment, then requests documentation.
FIRST VIEWPORT: Entry header with the vessel name and class line; the profile lines drawing spanning the page at scale with a scale bar and dimension callouts (L.O.A. 8,323 mm, freeboard 441 mm, draft 0.33 m); a dense particulars block beside/under it; the primary action set as the entry's Enquiries line, a real orange button.
FORM: Naval reference annual, grounded candidate 3 of 7; seed:2699968dd50caa43. Raises: change-state orange that holds (from gate board); two-ink total commitment (from datamatics); spec rows aligned to drawing stations (from coiled tower). Signature interaction: mission picker redraws payload on the drawing and lights changed particulars. Motion grammar: the drawing inks itself once on load; changed values hold their light.
